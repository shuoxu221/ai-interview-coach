# 清源 AI 求职 Skills

面向求职者的开源 AI 技能集合。当前包含简历事实核查与双模式模拟面试两个技能，统一坚持：先核对事实与指标口径，再优化表达，不编造经历。

## ai-resume-coach

适用于按 JD 审查和改写简历、修改项目经历但不编造销售数据、检查职责与指标口径，以及进行模拟的 30 秒 HR 初筛。

它不会编造项目、读取本地文件、自动投递岗位，或承诺面试与 Offer。

## ai-interview-coach

适用于根据目标岗位 JD 和脱敏简历进行模拟面试，解决回答空泛、经不起追问、逻辑混乱和不会复盘四类问题。

- **训练模式：** 一次一题，最多连续追问 3 轮，再给四维评分、缺口分析和重答机会。
- **实战模式：** 中途不提示、不评分、不纠错，结束后统一复盘。

它会检查简历与回答的事实冲突，但不会编造答案、询问无关敏感信息，或承诺真实录用结果。

## 安装

仓库发布到 GitHub 后，可从 `skills/ai-resume-coach` 或 `skills/ai-interview-coach` 安装。小红书 SkillHub 用户以 SkillHub 页面生成的正式安装口令为准。

不安装也能使用：

- [`prompts/AI改简历-普通AI复制版.md`](prompts/AI改简历-普通AI复制版.md)
- [`prompts/AI模拟面试-普通AI复制版.md`](prompts/AI模拟面试-普通AI复制版.md)

复制对应完整提示词到常用 AI，并粘贴脱敏后的 JD 与简历。
