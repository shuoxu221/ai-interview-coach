# 反馈与复盘模板

## 训练模式：单题反馈

### 四维评分

| 维度 | 分数（10分） | 依据 |
|---|---:|---|
| 内容与证据 |  | 引用用户原回答 |
| 逻辑结构 |  | 引用用户原回答 |
| 岗位匹配 |  | 对照 JD |
| 表达清晰 |  | 引用具体表达 |

### 面试官视角

- 最强证据：
- 可能的理解：
- 最大淘汰风险：
- 仍待确认的事实：

### 重答框架

只列结构和已确认事实：`背景/目标 → 本人判断与行动 → 可验证结果 → 对岗位的证明`。不得填入用户未提供的数字、动作或结果。

最后询问：`重答本题，还是进入下一题？`

## 实战模式：整场复盘

### 模拟结论

给出 `表现较强 / 有条件匹配 / 风险较高 / 信息不足`，并明确这是基于当前 JD、简历和本次回答的模拟判断，不代表真实招聘结果。

### 证据摘要

- 最有竞争力的 3 段回答；
- 最容易被淘汰的 3 个问题；
- 面试官可能对候选人的最大疑虑；
- 简历与回答中的事实冲突或待确认项。

### 四维总评

按内容与证据、逻辑结构、岗位匹配、表达清晰分别评分并引用原回答。不要输出虚构的综合通过率。

### 改进优先级

1. 立即修正：影响真实性或岗位匹配的问题；
2. 下一轮训练：最需要补强的 2—3 类问题；
3. 事实补充：需要用户回查的数字、边界或证据。

### 高频问题与回答思路

根据本次暴露的问题，整理 5—8 个高频问题。每题只提供结构、证据清单和追问风险；除非事实已经确认，不输出可直接背诵的“完美答案”。
